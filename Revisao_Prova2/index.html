Dia 1 • Fundamentos & Mental Model

JSX, Flexbox, Inputs e o poder do useState

Domine a atualização visual e entenda de uma vez por todas por que uma variável comum não redesenha a tela.

💡 A Grande Regra de Ouro do React Native
No JavaScript clássico alteramos o DOM diretamente. No React Native isso não existe. A tela é um reflexo direto do Estado. Se você quer que algo mude na tela (um texto, uma cor, o clique de um botão), você obrigatoriamente precisa alterar um useState.
Nível Fácil

1.1 Contador Simples com useState

Crie um componente com um número centralizado na tela e dois botões: "+1" e "-1". Ao clicar, o número na tela deve atualizar imediatamente.

import React, { useState } from 'react'; import { View, Text, Button, StyleSheet } from 'react-native'; export default function Contador() { const [contador, setContador] = useState(0); return ( <View style={styles.container}> <Text style={styles.numero}>{contador}</Text> <Button title="+1" onPress={() => setContador(contador + 1)} /> <Button title="-1" onPress={() => setContador(contador - 1)} /> </View> ); }
Por que funciona: contador guarda o valor e setContador avisa o motor do React Native: "Ei, redesenhe a tela com o novo valor!". Nunca faça contador = contador + 1, isso quebra a reatividade.
Nível Médio

1.2 Input de Texto Controlado (TextInput)

Crie uma tela de boas-vindas com um TextInput onde o usuário digita seu nome. Conforme ele digita, deve aparecer embaixo: "Bem-vindo, [Nome Digitado]!".

const [nome, setNome] = useState(''); <TextInput placeholder="Digite seu nome" value={nome} onChangeText={(texto) => setNome(texto)} /> <Text>{nome ? `Bem-vindo, ${nome}!` : 'Digite seu nome acima'}</Text>
Ponto de Prova: No React Native usamos onChangeText (que já passa a string direto), e não onChange(e.target.value) da web!

Dia 2 • Navegação Completa

Stack, Tabs e Troca de Parâmetros

Aprenda a fazer telas conversarem entre si: enviando dados com navigation.navigate e recebendo com route.params.

🗺️ O Mapa Mental da Navegação
Imagine que a Stack é uma pilha de pratos: quando você chama navigate('TelaB'), você coloca a Tela B por cima. Quando aperta voltar ou chama goBack(), retira o prato de cima e a Tela A volta a aparecer. Para passar a "encomenda":
• Enviar: navigation.navigate('Detalhes', { id: 10, nome: 'Pizza' })
• Abrir a encomenda na outra tela: const { id, nome } = route.params;
Nível Fácil

2.1 Configurando o Native Stack do Zero

Crie um arquivo AppStack.js que configure duas telas: Home e Detalhes com createNativeStackNavigator.

import { createNativeStackNavigator } from '@react-navigation/native-stack'; import Home from '../screens/Home'; import Detalhes from '../screens/Detalhes'; const Stack = createNativeStackNavigator(); export default function AppStack() { return ( <Stack.Navigator> <Stack.Screen name="Home" component={Home} options={{ title: 'Início' }} /> <Stack.Screen name="Detalhes" component={Detalhes} /> </Stack.Navigator> ); }
Nível Médio

2.2 Passagem e Leitura de Parâmetros (Produto / Música)

Na tela Home, ao clicar em um card de música, chame a tela Player enviando { titulo: "Bohemian Rhapsody", artista: "Queen" }. Na tela Player, mostre esses dados e crie um botão de voltar.

// Na tela Player.js: export default function Player({ route, navigation }) { // Desestruturação direta do route.params const { titulo, artista } = route.params; return ( <View style={styles.container}> <Text style={styles.titulo}>{titulo}</Text> <Text style={styles.artista}>{artista}</Text> <Button title="Voltar" onPress={() => navigation.goBack()} /> </View> ); }

Dia 3 • Listas & O Mistério da Atualização

FlatList, useEffect e o useFocusEffect

Descubra por que listas não atualizam sozinhas quando você volta de tela e como usar useFocusEffect para resolver isso de vez.

⚡ Por que a tela não atualizou ao voltar?
Quando você vai da Tela de Lista para a Tela de Cadastro e clica em Voltar, a tela de lista nunca foi descarregada da memória!
• O useEffect(() => {}, []) só roda quando o componente "nasce" (mount). Como ele já estava na memória, não roda de novo.
• O useFocusEffect roda toda vez que a tela ganha foco! É ele que você usa para recarregar a lista ao voltar de um cadastro.
Nível Fácil

3.1 FlatList Básica sem Travar

Crie uma FlatList que renderize uma lista estática de 4 produtos com id, nome e preco. Certifique-se de configurar data, renderItem e keyExtractor.

<FlatList data={produtos} keyExtractor={(item) => item.id.toString()} renderItem={({ item }) => ( <View style={styles.item}> <Text style={styles.itemNome}>{item.nome}</Text> <Text style={styles.itemPreco}>R$ {item.preco}</Text> </View> )} />
Nível Médio

3.2 Exclusão Reativa de Item (Filter)

Adicione um botão "Remover" em cada item da FlatList. Ao clicar, o item correspondente deve sumir imediatamente da tela usando filter no estado.

function removerItem(idParaRemover) { // Mantém na lista apenas quem tem id diferente do removido setProdutos(produtosAtuais => produtosAtuais.filter(item => item.id !== idParaRemover)); }
Nível Difícil

3.3 useFocusEffect na Prática (Código de Prova)

Escreva a estrutura exata do useFocusEffect combinada com useCallback para executar a função carregarDados() sempre que a tela for exibida.

import { useFocusEffect } from '@react-navigation/native'; import { useCallback } from 'react'; useFocusEffect( useCallback(() => { carregarDados(); // Roda ao abrir a tela E sempre que voltar de outra tela! }, []) );

Dia 4 • Conexão com Backend (API REST)

Fetch, Métodos HTTP, Loading e Tratamento de Erros

O conteúdo mais recente ensinado em sala: consumindo APIs com GET, POST e DELETE.

🌐 As 4 Operações Essenciais de API (CRUD)
• GET: Buscar dados do servidor (padrão do fetch(url)).
• POST: Criar novo registro (passa method: 'POST', headers: { 'Content-Type': 'application/json' } e body: JSON.stringify(objeto)).
• DELETE: Remover registro passando o id na URL (ex: fetch(`${url}/${id}`, { method: 'DELETE' })).
• ActivityIndicator: Componente nativo do React Native para exibir o "spinner" de carregamento.
Nível Fácil

4.1 Buscar Dados com GET e Loading

Crie a função carregarTarefas() que liga o setCarregando(true), faz o fetch, guarda a resposta no estado e desliga o loading no bloco finally.

async function carregarTarefas() { try { setCarregando(true); const resposta = await fetch('http://apiwp.smartcortex.ai:8888/tarefas'); const dados = await resposta.json(); setTarefas(dados); } catch (erro) { Alert.alert('Erro', 'Não foi possível carregar as tarefas'); } finally { setCarregando(false); } }
Nível Médio

4.2 Cadastrar Novo Registro com POST

Crie a tela de cadastro que envia um título e descrição para a API. Ao receber status de sucesso, emita um Alert.alert e faça navigation.goBack().

const resposta = await fetch('http://apiwp.smartcortex.ai:8888/tarefas', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ titulo: titulo, descricao: descricao, concluida: false }) }); if (resposta.ok) { Alert.alert('Sucesso', 'Cadastrado!', [ { text: 'OK', onPress: () => navigation.goBack() } ]); }
Nível Difícil

4.3 Excluir com DELETE e Alerta de Confirmação

Antes de chamar o endpoint de DELETE, abra um Alert.alert com dois botões: "Cancelar" e "Excluir". Se o usuário confirmar, faça a requisição e atualize o estado local.

Alert.alert('Excluir', 'Tem certeza?', [ { text: 'Cancelar', style: 'cancel' }, { text: 'Excluir', style: 'destructive', onPress: async () => { await fetch(`http://.../tarefas/${id}`, { method: 'DELETE' }); setTarefas(atuais => atuais.filter(t => t.id !== id)); } } ]);

Perguntas Teóricas e Como Desarmar Pegadinhas

Perguntas dissertativas reais baseadas no estilo das provas e nos slides da matéria.

1. O que é JSX e qual sua principal vantagem?

Resposta esperada: JSX é uma extensão de sintaxe para JavaScript que permite escrever a estrutura da interface do usuário de forma declarativa e semelhante ao HTML. Sua principal vantagem é a facilidade de leitura, organização visual dos componentes e melhor manutenção do código.

2. Qual é a diferença prática entre justifyContent e alignItems no StyleSheet?

Resposta esperada: O justifyContent alinha os elementos ao longo do eixo principal (por padrão vertical no React Native, pois flexDirection default é 'column'). Já o alignItems alinha os elementos no eixo secundário/transversal (por padrão horizontal).

3. O que é Comunicação Direta e Indireta entre componentes?

Resposta esperada:
• Direta: O componente Pai passa dados para o componente Filho através de props convencionais (ex: <Filho nome="Ana" />).
• Indireta: O componente Pai passa uma função de callback via props para o Filho. Quando o Filho executa essa função, ele consegue enviar dados de volta para o Pai (ex: <Filho aoSalvar={receberDados} />).

4. Por que usamos StyleSheet.create ao invés de estilos inline puros?

Resposta esperada: Por desempenho e organização. O StyleSheet.create processa e valida os estilos uma única vez, gerando referências numéricas internas (evitando que novos objetos de estilo sejam recriados na memória a cada renderização do componente).

5. Como solucionar o problema de uma tela não recarregar dados ao voltar nela?

Resposta esperada: Utilizando o hook useFocusEffect (junto com useCallback) do React Navigation em vez do useEffect com array vazio. O useFocusEffect detecta quando a tela ganha foco (ao ser aberta ou ao voltar de outra tela) e reexecuta a função de busca/atualização.

⚠️ 3 Erros Fatais em Prova que Você Deve Evitar

Erro 1: "Cannot read property 'params' of undefined"

Causa: Você tentou fazer const { id } = route.params, mas a tela foi aberta sem nenhum parâmetro enviado.
Como evitar: Use valor padrão ou verificação opcional: const { id } = route.params || {};

Erro 2: Loop Infinito com useState dentro de useEffect

Causa: Chamar setDados() dentro de um useEffect sem passar o array de dependências [] no final.
Como evitar: Sempre adicione [] como segundo parâmetro do useEffect se quiser que ele rode só uma vez na montagem.

Erro 3: Esquecer do 'await' ou do 'JSON.stringify' no fetch

Causa: Fazer body: { titulo } direto no fetch faz a API receber [object Object] e dar erro 400 ou 500.
Como evitar: Sempre use body: JSON.stringify({ titulo }) e cabeçalho 'Content-Type': 'application/json'.
